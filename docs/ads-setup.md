# Google の広告（AdSense・アド マネージャー）を動かす手順

アプリの側はできています。Google のアカウントを作り、ID を Vercel の環境変数に入れると、無料・ライトプランに Google の広告が出ます。
ID を入れるまでは、今までどおり自前の案内（有料プランの紹介）が出ます。

## AdMob ではない理由
- Google AdMob は、App Store・Google Play で配るスマホのアプリ（ネイティブアプリ）専用です
- このアプリは Web アプリ（PWA）なので、AdMob の広告は出せません
- Web で使える Google の広告は、AdSense とアド マネージャーです

## どこに、何の広告が出るか

| 枠 | 出るプラン | 使うもの | 広告が無いとき |
|---|---|---|---|
| 小さい広告（ホーム） | 無料・ライト | AdSense の広告ユニット | 自前の案内 |
| 小さい広告（AI 画面） | 無料 | AdSense の広告ユニット | 自前の案内 |
| 全画面広告 | 無料 | アド マネージャーの Web インタースティシャル | 自前の全画面の案内（開いたとき3時間に1回・AI の返事3回に1回） |

- 全画面広告を出すときは Google が決めます
  - アプリに戻ったとき・ブラウザの戻る操作のときなど
  - 間隔は、アド マネージャーの設定で決めます（初めは10分に1回まで）
  - 「AI の返事3回に1回」のように、アプリの側で出すときを決めることはできません
- AdSense の広告は、自分で作った全画面の枠に入れてはいけない決まりです。そのため、全画面にはアド マネージャーを使います
- スタンダード・プロでは、広告のプログラムを読み込みません
- 広告に、予定・チャット・カスタム指示の内容は渡しません（Google のカレンダーのデータを広告に使うのは、Google の決まりで禁止されています）

## 1. AdSense（小さい広告）

1. **独自のドメインにしておく**（おすすめ）
   - AdSense の審査は、サイトの持ち主かどうかと、サイトの中身を見ます
   - `vercel.app` のような共有のドメインだと、審査に通りにくいことがあります
   - ドメインを決めて Vercel につないでから申し込むと確実です
2. [Google AdSense](https://adsense.google.com/) でアカウントを作る
3. **サイトを追加する**（サイト → 新しいサイト）
   - 確認の方法は「AdSense コード スニペット」か「メタタグ」を選ぶ
   - このアプリは、4 の環境変数を入れると、メタタグ（`google-adsense-account`）を自動で出します
   - `ads.txt` も、`https://<ドメイン>/ads.txt` に自動で出します
4. **サイト運営者 ID**（`ca-pub-` で始まる16桁の数字）を Vercel の環境変数 `ADSENSE_CLIENT` に入れて、再デプロイする
5. AdSense で「審査をリクエスト」を押す。数日〜数週間かかります
   - 審査では、紹介ページ（`/lp`・`/lp/arc`）と、規約などのページが見られます
6. 審査に通ったら、**広告ユニットを2つ作る**（広告 → 広告ユニットごと → ディスプレイ広告）
   - 名前：「ホーム」「AI 画面」
   - 形：横長
   - できたコードの `data-ad-slot="…"` の数字を、それぞれ控える
7. Vercel に入れて、再デプロイする

| 名前 | 値 |
|---|---|
| `ADSENSE_CLIENT` | `ca-pub-…` |
| `ADSENSE_SLOT_HOME` | ホームの広告ユニットの数字 |
| `ADSENSE_SLOT_CHAT` | AI 画面の広告ユニットの数字 |

## 2. アド マネージャー（全画面広告）

1. [Google アド マネージャー](https://admanager.google.com/) に申し込む（AdSense のアカウントでログインして作れます）
2. **広告ユニットを作る**（在庫 → 広告ユニット → 新しい広告ユニット）
   - 名前：例 `ai15_interstitial`
   - サイズ：「フレキシブル」かインタースティシャル用のもの
3. **Web インタースティシャルを有効にする**
   - 管理 → 全般設定 などにある、インタースティシャルの設定を確かめる
   - 出す間隔（何分に1回まで）も、ここで決められます
4. **広告の出どころを決める**
   - いちばん簡単なのは、AdSense の広告で埋める設定（AdSense との連携・「AdSense で埋める」）です
5. ネットワーク コード（管理 → 全般設定 の数字）と広告ユニットの名前から、`/ネットワークコード/広告ユニットの名前` を作る
   - 例：`/21234567890/ai15_interstitial`
6. Vercel に入れて、再デプロイする

| 名前 | 値 |
|---|---|
| `GAM_INTERSTITIAL_UNIT` | `/ネットワークコード/広告ユニットの名前` |

- 確かめ方：アプリの URL の最後に `#gamInterstitialDemo` を付けて開くと、見本の全画面広告が出ます
- 小さい画面・古いブラウザなど、全画面広告に対応していないときは、自前の全画面の案内が出ます

## 3. そのほか
- **プライバシーポリシー**：AdSense は、第三者の広告と Cookie について書くことを求めています。`lib/legal.ts` に「5. 広告」として書いてあります
- **ヨーロッパ（EEA・英国・スイス）の人に出す場合**：同意の画面（CMP）が必要です。AdSense の「プライバシーとメッセージ」で Google の同意の画面を有効にしてください
- **Content-Security-Policy**：広告を使うときは、`proxy.ts` が Google の広告の通信先（`lib/ads.ts` の `AD_HOSTS`）を自動で許します
  - 広告が出ず、ブラウザのコンソールに CSP のエラーが出ていたら、その送り先を `AD_HOSTS` に足してください
- **ID の形**：決まった形でない値は使いません（`lib/ads.ts` の `adsConfig`）
  - `ca-pub-` と数字
  - 広告ユニットは数字だけ
  - アド マネージャーは `/数字/名前`
