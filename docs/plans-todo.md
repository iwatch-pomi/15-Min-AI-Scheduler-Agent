# やることメモ：プラン（無料／有料1／有料2）の仕組み

## 背景
- 実測：1回のチャットは約 $0.02（Sonnet）。10回で $0.20
- 今の 1日 $0.50 は約25回（通常モード）。毎日使い切る人は月 $15。無料版としては高すぎる
- 将来の形：**無料版（広告あり）／有料1（広告なし）／有料2（AI 使用量を大幅アップ）**

## 実装すること（まとめて行う）

### 1. ユーザーごとのプラン
- `users.plan`（`free` / `plus` / `pro`、既定は `free`）を `supabase/schema.sql` に追加
- `lib/plans.ts`（新規）に、プランごとの決まりをまとめる
  - 月の予算・1日の予算・使えるモード・広告の有無
- 変更はひとまず Supabase で手で行う（Stripe での課金は別の作業）
- マイページに今のプランと、プランごとの違いを表示

### 2. 月の上限（1日の上限と両方）

| プラン | 月の予算 | 1日の予算 | 目安（通常モード） |
|---|---|---|---|
| 無料（広告あり） | $0.5 | $0.05 | 1日2〜3回・月25回 |
| 有料1（広告なし）例 480円/月 | $1.2 | $0.10 | 1日5回・月60回 |
| 有料2（AI 大幅アップ）例 1,480円/月 | $4.5 | $0.50 | 1日25回・月220回 |

- 金額は仮の値。環境変数か `lib/plans.ts` で変えられるようにする
- `lib/budget.ts` の `withAiBudget`
  - 今は1日の費用だけを見ている。月の合計（usage テーブルの当月分の合計）も確かめる
  - どちらかを超えたら `BudgetExceededError` にする。理由（今日／今月）をメッセージで分ける
  - 先に押さえる額（`RESERVE_USD`）は、月の合計にも入れる
- `lib/limits.ts` の `usageOf`：残りは「今日」と「今月」の少ないほうを % で出す
- 画面（`UsageMeter`）：今月の残りも出す。上限に達したら、有料プランへの案内を出す
- 1日の予算は、月の予算÷30より多めにする（使わない日の分を、使う日に回せるように）

### 3. プランごとに使えるモード
今のモード（2026-10-28 時点）：節約・通常＝Haiku（難しい依頼は Sonnet）／強化＝Sonnet／最大＝Opus（直近2週間の振り返り・時間の浪費の分析向け）
- 無料：節約・通常（どちらも Haiku 中心なので安い）
- 有料1：節約・通常・強化（Sonnet）
- 有料2：節約・通常・強化・**最大（Opus）**。**最大モードは、いちばん高いプランだけ**（ユーザーの決定）
- サーバー（`/api/chat`・`/api/suggestions`）で、プランに無いモードが来たら、使えるいちばん上のモードに下げる（画面だけに頼らない）
- マイページの切り替えで、使えないモードは鍵の印を付けて押せなくし、案内を出す

### 4. 広告の枠
- 無料プランだけに出す。場所の候補：ホームの「AIのおすすめ／AI BRIEF」の下、AI 画面の上部
- まずは枠（`components/AdSlot.tsx`）だけ作り、中身は差し替えられるようにする
- 広告の事業者（AdSense など）を決めたら、`proxy.ts` の Content-Security-Policy に、その事業者のドメインを足す（script-src・img-src・frame-src・connect-src）
- 広告の文字・リンクが、予定の情報（AI に渡す文脈）に混ざらないようにする
